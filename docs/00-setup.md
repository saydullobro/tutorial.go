# 00. Установка и инструменты

[← К оглавлению](../README.md) · [Дальше: основы синтаксиса →](01-basics.md)

## Чем Go отличается от Python на уровне «как это запускается»

| | Python | Go |
|---|---|---|
| Исполнение | интерпретатор (`python app.py`) | компиляция в один бинарный файл |
| Типизация | динамическая, подсказки типов опциональны | статическая, проверяется компилятором |
| Что нужно на сервере | Python + venv + зависимости | только сам бинарник |
| Окружения | `venv`, `poetry`, `uv` | не нужны: зависимости описаны в `go.mod` |
| Форматирование | `black`, `ruff format` (настраиваются) | `gofmt` — один стиль на всех, без настроек |
| Параллелизм | GIL, `asyncio`, `multiprocessing` | горутины на всех ядрах «из коробки» |

Главное следствие: огромная часть ошибок, которые в Python всплывают в рантайме
(`AttributeError`, `TypeError`, опечатка в имени), в Go ловится на этапе компиляции.

## Установка

Скачай установщик с <https://go.dev/dl/> или поставь через пакетный менеджер:

```bash
# macOS
brew install go

# Ubuntu / Debian (версия в репозитории может быть старой — надёжнее архив с go.dev)
sudo apt install golang-go
```

Проверка:

```bash
go version
```

Материалы этого репозитория рассчитаны на **Go 1.24 и новее**.

## Первая программа

```bash
mkdir hello && cd hello
go mod init example.com/hello
```

`go mod init` создаёт файл `go.mod` — это аналог `pyproject.toml`: имя модуля,
версия Go и список зависимостей.

Файл `main.go`:

```go
package main

import "fmt"

func main() {
	fmt.Println("Привет, Go!")
}
```

Запуск:

```bash
go run .
```

Что здесь важно:

- `package main` + `func main()` — точка входа. Аналог `if __name__ == "__main__":`,
  только обязательный и единственный.
- Отступы — табы. Не спорь с этим: `gofmt` всё равно расставит по-своему.
- Фигурные скобки обязательны, открывающая — всегда на той же строке.
- Точки с запятой не пишутся.

## Основные команды

| Команда | Что делает | Аналог в Python |
|---|---|---|
| `go run .` | скомпилировать и сразу запустить | `python app.py` |
| `go build` | собрать бинарник в текущую папку | — (ближе всего `pyinstaller`) |
| `go test ./...` | запустить все тесты модуля | `pytest` |
| `go fmt ./...` | отформатировать код | `black .` |
| `go vet ./...` | статический поиск подозрительных мест | `ruff check` (частично) |
| `go mod tidy` | добавить недостающие и убрать лишние зависимости | `uv sync` / `pip-compile` |
| `go get пакет@версия` | добавить или обновить зависимость | `pip install` / `uv add` |
| `go install пакет@latest` | собрать и установить CLI-утилиту в `~/go/bin` | `pipx install` |
| `go doc fmt.Println` | документация в терминале | `help(print)` |
| `go env` | настройки окружения Go | — |

`./...` означает «этот пакет и все вложенные».

## Сборка и кросс-компиляция

```bash
go build -o app .
```

Получается один исполняемый файл без внешних зависимостей. Собрать под другую
ОС можно с той же машины — достаточно двух переменных окружения:

```bash
GOOS=linux GOARCH=amd64 go build -o app-linux .
```

```bash
GOOS=windows GOARCH=amd64 go build -o app.exe .
```

Именно поэтому Docker-образы с Go-сервисами бывают размером 10–20 МБ:
внутри только бинарник.

## Редактор

- **VS Code** + официальное расширение *Go* (внутри работает языковой сервер `gopls`).
- **GoLand** от JetBrains — если привык к PyCharm, будет знакомо.

Включи «форматировать при сохранении» — в Go это норма, а не вкусовщина.

## Линтеры

- `go vet` — встроенный, запускай всегда.
- [`golangci-lint`](https://golangci-lint.run/) — агрегатор линтеров, по роли ближе всего к `ruff`.
- `go test -race` — детектор гонок данных (подробнее в [главе про конкурентность](06-concurrency.md)).

## Строгость компилятора, к которой надо привыкнуть

Эти вещи — не предупреждения, а **ошибки компиляции**:

```go
package main

import (
	"fmt"
	"os" // ошибка: импорт не используется
)

func main() {
	x := 10 // ошибка: переменная объявлена и не используется — не скомпилируется
	fmt.Println("привет")
}
```

Сначала раздражает, потом понимаешь, что мёртвого кода в проекте просто не бывает.
Временно «заглушить» переменную можно так: `_ = x`.

## Практика

1. Установи Go, создай модуль, запусти `hello`.
2. Собери бинарник через `go build` и запусти его напрямую.
3. Намеренно сломай форматирование и запусти `go fmt ./...` — посмотри, что изменилось.
4. Добавь неиспользуемую переменную и прочитай сообщение компилятора.
