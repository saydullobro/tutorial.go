# tutorial.go

Техническая документация по Go для тех, кто приходит из Python.

Материал не объясняет, что такое переменная или цикл. Вместо этого каждая
тема подаётся через сравнение: «в Python ты делал так — в Go это устроено
вот так, и вот где ты споткнёшься».

- **Версия Go:** 1.24 и новее.
- **Примеры:** все Go-примеры из документации проверены компилятором Go 1.24.

## Как проходить

1. Читай главы по порядку — каждая опирается на предыдущие.
2. Каждый пример **набирай руками** и запускай, а не копируй.
3. Меняй примеры и ломай их: сообщения компилятора Go — часть обучения.
4. В конце каждой главы есть раздел «Практика» — выполняй задания до перехода дальше.
5. Шпаргалку из главы 10 держи открытой с первого дня.

Быстро попробовать код без установки: <https://go.dev/play/>.

## План на 6 недель

Рассчитан на 1–1,5 часа в день при наличии опыта программирования.

| 2 | 03, 04 | моделируешь предметную область структурами и интерфейсами |
| 3 | 05, 07, 08 | раскладываешь код по пакетам, обрабатываешь ошибки, пишешь тесты |

| 6 | проект | собственный сервис от идеи до бинарника |

## Идеи проектов

От простого к сложному:

1. **CLI-утилита** — аналог `wc` или `grep`: флаги, файлы, строки.
2. **Менеджер задач в терминале** с хранением в JSON-файле: структуры, JSON, тесты.
3. **Параллельный проверяльщик ссылок**: читает список URL, проверяет пулом
   воркеров с таймаутами.
4. **REST API «список задач»** на `net/http` с хранением в памяти, тестами
   через `httptest` и middleware для логов.
5. **То же API с PostgreSQL**: `pgx`, миграции, `context`, graceful shutdown, Docker.
6. **Сокращатель ссылок** или **чат на WebSocket** — конкурентность в реальной задаче.

Хороший способ закрепить: возьми небольшой сервис, который ты уже писал на
Python (FastAPI / Flask), и перепиши на Go.

## Что читать дальше

Официальное:

- [A Tour of Go](https://go.dev/tour/) — интерактивный тур, пройди параллельно с главами 01–04.
- [Effective Go](https://go.dev/doc/effective_go) — как писать идиоматично.
- [Go by Example](https://gobyexample.com/) — короткие примеры на каждую тему.
- [Документация стандартной библиотеки](https://pkg.go.dev/std).
- [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments) — частые замечания на ревью.
- [Блог Go](https://go.dev/blog/) — разборы новых возможностей от авторов языка.

Книги:

- *Learning Go* (Jon Bodner) — лучшая первая книга для тех, у кого уже есть опыт.
- *100 Go Mistakes and How to Avoid Them* (Teiva Harsanyi) — после первого проекта.
- *Concurrency in Go* (Katherine Cox-Buday) — глубоко про горутины и каналы.

Практика:

- [Learn Go with Tests](https://quii.gitbook.io/learn-go-with-tests) — изучение языка через TDD.
- [Exercism: Go track](https://exercism.org/tracks/go) — задачи с менторским ревью.
